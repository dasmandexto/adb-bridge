WebUSB-to-TCP ADB Bridge

Дистанційне керування Android з консолі Debian через Windows Chrome WebUSB

📋 Інструкція для користувача Windows:

  1. Підключіть ваш Android смартфон до Windows через USB-кабель.
  2. Увімкніть «Налагодження по USB» (USB Debugging) у меню «Для розробників» на телефоні.
  3. Якщо на Windows запущено локальний adb, вимкніть його в PowerShell: adb kill-server.
  4. Натисніть кнопку «⚡ Підключити Android» нижче та виберіть телефон у списку вікна Chrome.
  5. Підтвердіть запит «Дозволити налагодження по USB з цього комп'ютера?» на екрані телефона.

🐧 Команди для адміністратора на Debian:

Після того, як статус вище зміниться на «Міст активний», виконайте на Debian: 

# Швидке підключення однією командою:
adb-go

# Або вручну:
adb connect 127.0.0.1:5555
adb -s 127.0.0.1:5555 shell
